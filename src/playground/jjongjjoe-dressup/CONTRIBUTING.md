# 죵쬐 옷 기여하기

1. 사이트의 제작 가이드 PNG를 내려받습니다. 캔버스는 768 × 832입니다.
2. 새 레이어에 옷만 그립니다. 가이드를 숨기고 투명 PNG로 저장합니다.
3. 사이트에서 PNG를 불러와 위치/크기/팔과의 겹침을 맞춥니다.
4. '공용 옷장에 제안하기'에서 옷 이름·제작자를 입력하고 PNG와 JSON을 내려받습니다.
5. GitHub 제안 글을 열고 두 파일을 첨부합니다. 공유 권한과 사용할 수 있는 범위를 함께 적습니다.

파일은 브라우저에서만 처리합니다. 제안 글을 직접 제출하기 전에는 서버에 전송되지 않습니다. 새로고침하면 불러온 옷은 사라지므로 파일을 저장해주세요.

기본 캐릭터는 옷이 없어도 온전한 흰색 몸이 남습니다. 투명 PNG 옷은 이 몸 위에 겹쳐집니다. 제작 가이드의 몸 위치를 참고하되 기존 의상 모양에 맞출 필요는 없습니다. 눈/입은 얼굴 배경이 포함된 원본 부위 레이어입니다. 정지 이미지용이며 펫 애니메이션 시트로 내보내지 않습니다.

## 운영자 등록

제출자의 공유 권한·제작자 표기·PNG 크기·투명도와 몸 위의 위치가 자연스러운지 확인합니다. 이미지 파일을 `assets/`에 넣고 `catalog.js`에 다음 항목을 추가합니다.

```js
{ id: 'unique-outfit-id', category: 'clothes', name: '옷 이름', author: '제작자', src: 'assets/unique-outfit.png', order: 40 }
```

팔 앞에 표시할 의상은 `order: 70`을 사용합니다. 파일과 이름에는 경로 탈출이나 외부 URL을 사용하지 않습니다. `npm test` 후 브라우저에서 조합과 PNG 저장을 확인합니다.

캐릭터 원작: 치지직 스트리머 달콤레나. 팬이 만든 Playground이며 원작자의 공식 서비스가 아닙니다.
