# 죵쬐 옷장

달콤레나의 죵쬐를 기본 몸 위에 옷과 소품을 씌우는 정지 이미지 옷입히기 게임으로 제공한다. `/playground/jjongjjoe-dressup/`에서 별도 로그인 없이 이용한다.

## 조합
기본 몸은 옷을 선택하지 않아도 온전하게 표시되는 단순한 흰색 만화 몸이다. 기존 얼굴·머리·꼬리 및 눈·입·팔 선택 이미지를 유지한다. 생성한 기본 몸의 몸통/다리 부분만 분리해서 사용한다. 의상은 기본 몸을 삭제하거나 빈 영역을 채우지 않고 그 위에 합성한다. 기본 의상으로 돌아가거나 옷을 벗길 수 있다.

## 팬 의상
방문자는 투명 PNG를 브라우저에서 불러와 위치·배율·팔 앞뒤 순서를 조정한다. 옷별 편집 상태를 유지한다. 새로고침하면 불러온 파일은 사라지므로 조정된 PNG와 정보 JSON을 내려받을 수 있다. 768×832 제작 템플릿과 기본 몸 가이드를 제공한다. 작은 소품이나 부분 의상도 기존 의상 영역을 채울 필요 없이 겹칠 수 있다.

## 저장과 공유
조합을 투명 PNG로 저장한다. 다운로드를 지원하지 않는 내장 브라우저를 위해 이미지를 열어 직접 저장하는 대안을 제공한다. 공용 등록은 GitHub 이슈에 파일과 제작자 정보, 공유 가능 범위를 직접 제출하고 운영자가 확인한 뒤 목록에 추가하는 방식이다. 자동 공개 업로드 서버는 없다.

## 확인
단위 테스트, 기존 사이트 빌드, 데스크톱·모바일 UI, 의상/표정/팔 선택, 위치·배율과 제작자 정보 유지, 투명 PNG 인코딩을 확인한다. 기본 몸과 기본 의상 착용 모두에서 몸의 빈 영역과 기존 의상 잔상이 없는지 육안으로 확인한다.
